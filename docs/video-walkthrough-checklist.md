# Video Walkthrough Checklist

Use this for your 3-5 minute explanation video.

## Suggested Flow
1. Introduce the assignment and say you chose Option B.
2. Show the registration and login flow.
3. Show persona selection.
4. Create a new conversation.
5. Send multiple prompts to demonstrate multi-turn history.
6. Mention that chat history is stored per user in the database.
7. Show where the LLM integration happens in `server/src/services/llm.ts`.
8. Explain that mock mode is enabled until a real API key is added.
9. Briefly show the Prisma schema and overall folder structure.
10. Close with what you would improve next if given more time.
